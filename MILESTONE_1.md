# Milestone 1 – GE Calculator 2.0 Core

## Definition of Done

- kompakte Wurstbrot-Datenbank wird geladen
- direkte und indirekte Startfahrzeuge A werden unterstützt
- Pflichtvorgänger des Ziels werden berechnet
- bereits durch A belegte Vorgänger werden nicht doppelt berechnet
- Rangfreischaltungen werden erfüllt
- Zusatzfahrzeuge werden kostenoptimiert gesucht
- GE werden je Fahrzeug einzeln aufgerundet
- angeforschte RP, vorhandene GE, convertible RP und SL-Rabatte werden berücksichtigt
- Explain Mode listet jede Position nachvollziehbar auf
- Desktop-GUI ist benutzbar
- Unit Tests und Regressionstest sind enthalten

## Nicht Teil dieses Meilensteins

- originalgetreuer visueller Tech Tree
- automatische Account-Synchronisierung
- fertige portable EXE ohne Python
- vollständiger formaler Beweis des globalen Minimums für jeden extrem verzweigten Rangfall
