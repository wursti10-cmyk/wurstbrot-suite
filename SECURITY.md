# Sicherheit

Bitte Sicherheitsprobleme nicht als öffentliches Issue melden. Nutze stattdessen die
private Sicherheitsmeldung (`Security` → `Report a vulnerability`) des GitHub-Repositories.

Unterstützt wird aktuell ausschließlich die neueste Beta-Version. Die Suite verarbeitet
Datamine-Dateien lokal; sie benötigt keine Zugangsdaten zu War Thunder oder Gaijin.
