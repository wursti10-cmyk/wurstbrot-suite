# Mitwirken

Danke für dein Interesse an der Wurstbrot Suite.

## Fehler melden

Bitte bei Fehlern möglichst angeben:

- War-Thunder-Version
- Startfahrzeug A
- Zielfahrzeug B
- erwartetes Ergebnis
- tatsächliches Ergebnis
- verwendete Datenbankdatei

## Pull Requests

- kleine, nachvollziehbare Änderungen
- keine proprietären Spielassets
- Tests für neue Berechnungslogik
- klare Commit-Nachrichten
