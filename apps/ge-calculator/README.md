# GE Calculator 2.0

Dieses Modul wird die eigentliche A → B Berechnung enthalten.

Geplante Eingaben:

- Startfahrzeug A
- Zielfahrzeug B
- vorhandene Fahrzeuge
- angeforschte RP
- convertible RP
- vorhandene GE

Geplante Ausgaben:

- fehlende RP
- benötigte GE
- benötigte SL
- vollständige Begründung pro Fahrzeug
